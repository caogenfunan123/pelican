# Hello World

欢迎来到我的 **Pelican 博客**！这是第一篇文章。

## 关于 Pelican

Pelican 是一个用 Python 编写的静态网站生成器，具有以下特点：

- 使用 Markdown 或 reStructuredText 编写内容
- 支持主题和插件
- 生成静态 HTML，部署方便
- 支持 Atom / RSS 订阅

## 快速开始

你可以使用 Markdown 来编写文章，Pelican 会自动将其转换为 HTML 页面。

```bash
pelican content -o output -s pelicanconf.py
```
